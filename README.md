# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。

## 流程

制片步骤：取样 → 切割 → 研磨 → 染色 → 观察。

- 记录到“观察”只表示制片完成，切片进入**待复核**，不代表可交付。
- 复核需填写**复核人**与**观察结论**；复核人不能与该切片最近一次步骤记录的操作人相同。
- 复核可“通过”或“退回”。退回时记录返工原因并回到指定制片步骤重做。
- 样本下**所有切片复核通过**后状态为“可交付”，此时才允许交付；页面交付按钮在未满足时禁用，接口同样拦截。
- 已交付样本返工：先撤销交付（交付记录留档为“已撤销”），所有切片回到指定步骤重做；旧复核结论、旧观察与交付记录均留档，但不计入当前状态与交付统计。

## 代码结构

- `lib/flow.js`：流程判断（纯函数，无文件 IO），如最近操作人、待复核/可交付判定、返工状态、样本状态推导。
- `lib/store.js`：数据写入（加载、落库、复核、返工、交付），并兼容旧数据字段。
- `server.js`：HTTP 路由与页面交互，仅做参数收发和展示，不直接包含流程规则。

原有“记录步骤”入口保留，新增操作人字段；卡片展示待复核、可交付与返工原因。
